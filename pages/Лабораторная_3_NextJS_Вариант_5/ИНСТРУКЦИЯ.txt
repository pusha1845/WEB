ЗАПУСК НА ДРУГОМ ПК С WINDOWS
1. Установите Node.js 24 LTS с официального сайта https://nodejs.org/.
   Допускается Node.js 22. При установке оставьте npm и добавление в PATH.
   Если Node.js уже установлен, проверьте в терминале: node -v и npm -v.
2. Полностью распакуйте архив в отдельную папку. Не запускайте cmd внутри ZIP.
3. Дважды нажмите start.cmd. При первом запуске он выполнит npm ci.
   Для скачивания зависимостей нужен интернет; установка может занять несколько минут.
4. Откройте http://localhost:3000. Если браузер открылся раньше готовности
   сервера, обновите страницу после появления сообщения Ready в окне.
5. Окно start.cmd должно оставаться открытым. Остановка: Ctrl+C.
   Если порт 3000 занят, остановите прежний сервер или запустите вручную
   npm run dev -- --port 3001 и откройте http://localhost:3001.

РУЧНОЙ ЗАПУСК — WINDOWS, LINUX И MACOS
Откройте терминал в папке project и выполните:
  npm ci
  npm run dev
В PowerShell при запрете запуска npm.ps1 используйте npm.cmd ci и npm.cmd run dev.
Для производственного режима вместо npm run dev:
  npm run build
  npm start

ПОВТОРНАЯ ПУБЛИКАЦИЯ НА VERCEL
Импортируйте GitHub-репозиторий в Vercel, выберите Next.js, Root Directory ./,
Node.js 24.x, команду установки npm ci и сборку npm run build.
Если в репозиторий загружена папка project целиком, Root Directory = project.
В Storage создайте Public Blob Store и подключите к проекту.
Vercel автоматически добавит BLOB_READ_WRITE_TOKEN; выполните Redeploy.
На Vercel локальный JSON нельзя использовать как постоянное хранилище;
поэтому опубликованная версия сохраняет анкеты отдельными JSON-файлами в Blob.
Токены и секреты в архив не включены и для локального запуска не требуются.

ЕСЛИ НЕ ЗАПУСКАЕТСЯ
«node не найден»: установите Node.js и заново откройте терминал/start.cmd.
Ошибка npm ci: проверьте интернет и доступ к registry.npmjs.org, затем повторите.
EADDRINUSE: порт занят, остановите другой процесс сервера или выберите другой порт.
На публичном сайте ошибка хранилища: проверьте подключение Blob и выполните Redeploy.
Для переноса используйте весь архив: одного start.cmd или отдельных js-файлов недостаточно.
